SubSensei Privacy Policy

Last updated: 2026-09-15

SubSensei is a browser extension that overlays synced Japanese subtitles on Crunchyroll (and, experimentally, Netflix), generates furigana readings on your device, and provides a hover dictionary for Japanese learners. This policy describes exactly what data the extension handles and where it goes.

SubSensei now operates a backend service of its own: the shared subtitle library at subsensei.tanrenworks.com. Earlier versions of this policy stated that SubSensei had no backend and collected no data. That is no longer accurate. The extension automatically contributes the Japanese subtitles it aligns, and automatically reuses subtitles other people have contributed, so that episodes load quickly for everyone. The sections below describe precisely what is sent, what is stored, and for how long.

SubSensei does not sell your data or share it with data brokers, requires no SubSensei account or signup, and never sends your Jimaku API key anywhere except Jimaku.

The shared subtitle library

Using the shared library requires no SubSensei account, sign-in or subscription. It has two halves, and both are automatic.

Automatic lookups

When you open an episode, the extension asks the library whether a subtitle for it is already known. A lookup sends only four things about the episode — the platform, the platform's episode ID, a timing fingerprint of the player's own subtitle track, and the alignment-engine version — plus an installation identifier (below). It does not send the show title. Lookups happen for every user, with no account token.

Automatic contributions

After the extension performs a new alignment using your Jimaku API key, it sends a contribution summary to the library. If the result is not already known, it also uploads the original Jimaku subtitle file. A contribution includes:

  • The show or movie display title, the episode number and episode title, and the platform's episode ID.
  • The original Japanese subtitle file, as downloaded from Jimaku.
  • Alignment details — the computed timing transform, the timing fingerprint of the reference track, the alignment-engine version, subtitle provenance and alignment diagnostics.

This collection has no opt-out setting and applies to all use of the extension. Uploads happen in the background and do not delay playback.

A contribution is not generated by subtitle or reference files you load manually, by your own personal sync adjustments, by rejected subtitle candidates, or when a subtitle is reused from the shared cache or your local cache.

Identifiers

The extension generates a random installation identifier (UUID) automatically — it is not tied to your name, email or any account — and sends it with lookups and contributions. The server does not store it as-is: using a server-only secret, it derives an HMAC pseudonym of that identifier and a second pseudonym of the network address that Cloudflare reports for the request (the address itself for IPv4; a normalized /64 prefix for IPv6). Only those pseudonyms are stored, and they are used to de-duplicate reports and limit abuse. They are not included in stored subtitle files or in responses sent to other users.

This amounts to pseudonymous collection of episode activity. We state that plainly rather than claiming that no data is collected.

A contribution never includes the page URL, the streaming or video URL, the text or full timing track of the platform's own subtitles, or your Jimaku API key.

Reporting a subtitle problem

If a shared subtitle is wrong, you can report it yourself from the extension popup. Nothing is sent unless you choose a problem and press "Send report". A report contains:

  • Which cached subtitle you are reporting, plus the same episode identity used for lookups.
  • The problem category you picked (timing early, timing late, timing drift, wrong episode, wrong language, or missing dialogue).
  • Where it happens (around this point, from this point onward, or throughout the episode) and, for timing problems, your rough estimate of how far out of sync it is.
  • Your playback position in the episode at the moment you report, and any manual sync offset you had applied. Both help reproduce the problem.
  • The extension version.

You get one report per subtitle, which you can edit by sending it again or retract with "Undo report". Reports are stored against the pseudonymous identifiers described above and are reviewed by the maintainer, who may mark them confirmed or dismissed.

Every network request the extension makes

DataWhere it goesWhy
Episode identity, timing fingerprint, installation identifier; contributed subtitles and alignment details SubSensei shared library (subsensei.tanrenworks.com, hosted on Cloudflare) Reuse and contribute aligned subtitles, as described above.
The anime series title shown on the page AniList (graphql.anilist.co) Resolve the title to an AniList ID so the right subtitle can be found.
AniList ID + episode number + your Jimaku API key Jimaku (jimaku.cc) Download the matching Japanese subtitle file.
Japanese word/phrase you hover over Jisho (jisho.org) Return the dictionary definition shown in the popup.
Crunchyroll's own subtitle track URL Crunchyroll CDN Fetch the platform's timed subtitle used as the alignment reference.
Netflix's own timed-text (TTML) track and on-page episode metadata Netflix (www.netflix.com) Identify the title/episode and use the platform track as the alignment reference. Netflix support is experimental.

These requests happen only while you are on a supported watch page and only in response to your activity (watching an episode, hovering a word, sending a report). Apart from the first row, which is SubSensei's own service, each of these is a third party with its own privacy policy governing the request.

Processing that stays on your device

Furigana — the hiragana readings shown above kanji — are generated entirely in your browser, using a Japanese morphological dictionary bundled inside the extension (about 18 MB, which is why the download is large). No subtitle text is transmitted to produce them. Subtitle alignment itself also runs locally.

What is stored on your device

Local extension data is stored in your browser via chrome.storage.local:

  • Your settings (overlay font size, color, position, dual-subtitle, furigana and debug toggles).
  • Your Jimaku API key, which you enter yourself. It is stored locally and only ever sent to Jimaku to authenticate subtitle downloads.
  • Your installation identifier (the random UUID described above).
  • A queue of pending contributions that could not be sent immediately. It holds at most ten uploads, and entries expire after 24 hours or eight attempts.
  • A local cache of aligned subtitle cues, keyed by episode, so repeat views are instant and work offline. This cache is bounded and evicts oldest entries automatically. You can clear it any time from the popup ("Clear subtitle cache").

Debug diagnostics, when enabled, record timings such as how long a cache lookup took. They stay on your device.

What is stored on SubSensei's servers, and for how long

  • Contributed subtitle files and alignment metadata are kept in a private Cloudflare R2 bucket. No R2 credential is ever given to users. These files are retained so the library keeps working.
  • Alignment evidence, catalog indexes and problem reports are kept in a Cloudflare D1 database, against the pseudonyms described above, until the maintainer removes them.
  • Request-rate records used for abuse control expire after 48 hours.
  • Any request logging or retention performed by Cloudflare as the hosting provider is configured separately by the operator and is governed by Cloudflare's own terms.

Site access

The extension requests access only to Crunchyroll, Netflix, Jimaku, AniList, Jisho and its own API host. Release builds pin the exact API host. Unpacked developer builds may additionally request optional access to *.workers.dev and localhost so a developer can point the extension at a test server; these are never used by store builds.

What the extension does NOT do

  • No third-party analytics services, advertising SDKs, tracking pixels, or browser fingerprinting. (The extension does send the pseudonymous episode activity described above to its own library — see that section rather than relying on this bullet.)
  • No advertising, and no sale or sharing of data with data brokers.
  • No SubSensei account, signup, password or payment — and so no collection of personal information such as your name, email or payment details.
  • No transmission of your Jimaku API key to anyone but Jimaku.
  • No transmission of page URLs, streaming URLs, or the platform's own subtitle text.
  • No access to pages other than the sites listed under "Site access".

Note that contributions do include alignment diagnostics, so the library does receive technical information about how alignment performed on your device.

Removing your data

Uninstalling the extension removes everything stored on your device — settings, your Jimaku API key, your installation identifier, the pending contribution queue and the subtitle cache. You can also clear the subtitle cache and your API key from the popup and options page at any time.

Uninstalling does not remove data already contributed to the shared library. Contributed subtitle files and the pseudonymous alignment evidence and reports derived from them remain until the maintainer removes them. Because the library has no accounts, there is no self-service deletion page. If you want a contribution or report removed, email the address below with enough detail to identify it (for example the show and episode), and I will remove it where it can be identified.

You can retract a subtitle problem report yourself at any time with "Undo report" in the popup.
